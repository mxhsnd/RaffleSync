# 临时测试名单数据替换设计

## 背景

项目当前在 `data.js` 中通过姓氏、名字数组随机生成 5 个学院各 600 人的测试名单。现在需要改为使用 `数据参考/360032384_按文本_又至毕业别离季，歌声献礼致青春。歌曲串烧投票_366_366.xlsx` 中的表格数据，提取班级和姓名，生成一份临时测试数据，并替换现有随机生成数据。

## 目标

- 从 Excel 表格中提取“1、您的班级：”和“3、您的姓名：”。
- 不保存手机号、IP、投票内容等无关或敏感字段。
- 生成当前抽奖系统可直接使用的 `studentData` 静态数组。
- 保留当前系统的 5 个学院设置，支持普通抽奖和学院特殊礼物抽奖继续工作。
- 为每条临时记录补充稳定的临时 `studentId`，用于现有去重、重抽和展示逻辑。

## 数据来源与清洗

数据来源文件为：

`数据参考/360032384_按文本_又至毕业别离季，歌声献礼致青春。歌曲串烧投票_366_366.xlsx`

处理规则：

1. 读取第一张工作表。
2. 定位并提取两列：
   - 班级：`1、您的班级：`
   - 姓名：`3、您的姓名：`
3. 去掉班级或姓名为空的记录。
4. 排除明显无效的测试/误填记录：班级和姓名都缺乏有效文本语义的记录，例如班级为 `1` 且姓名为 `1`。
5. 单字姓名保留，因为可能是真实填写。
6. 输出仅包含抽奖需要字段：`college`、`className`、`name`、`studentId`、`isDrawn`。

## 学院归类规则

系统继续使用当前 5 个学院：

- `安全科学与工程学院（应急管理学院）`
- `工商管理学院`
- `电气与控制工程学院`
- `电子与信息工程学院`
- `软件学院（人工智能学院）`

班级前缀归类如下：

| 班级前缀 | 归属学院 |
| --- | --- |
| 软件、网络、数据、智能、计算 | 软件学院（人工智能学院） |
| 电气、电网、自动、自动化、智控、测控 | 电气与控制工程学院 |
| 电信、电子、通信 | 电子与信息工程学院 |
| 工商、工管、会计、信管、国贸、金融、商务、营销 | 工商管理学院 |
| 其他无法识别前缀 | 安全科学与工程学院（应急管理学院） |

选择这个归类方式是因为用户确认“就是现在系统里的五大院，先分，不对再改”。无法从班级前缀可靠判断到前四类的记录，先统一放入安全科学与工程学院，保证数据都能参与抽奖并保持 5 个学院结构稳定。

## `data.js` 结构

保留现有 `colleges` 常量，供控制台的学院特殊礼物抽奖面板继续使用。

将当前随机生成逻辑替换为静态数组：

```js
const studentData = [
  {
    college: '软件学院（人工智能学院）',
    className: '软件22-16',
    name: '陈作国',
    studentId: 'TEMP0001',
    isDrawn: false
  }
];
```

临时编号规则：

- 按 Excel 中记录顺序生成。
- 格式为 `TEMP0001`、`TEMP0002`、……。
- 编号只用于当前前端状态管理，不代表真实学号。

## 受影响组件

- `data.js`：替换随机数据生成逻辑为静态临时名单。
- `control.js`：不需要改动。它已使用 `studentData`、`college`、`className`、`name`、`studentId`、`isDrawn` 字段。
- `display.js`：不需要改动。展示端接收赢家对象并展示现有字段。
- `admin.html`：可选更新默认状态文案中的“3000 名测试学生”，改为根据实际临时名单数量或通用文案，避免与实际数据不一致。

## 验证方式

实现后检查：

1. `data.js` 不再包含随机姓名生成数组和 `Array.from({ length: 600 })`。
2. `studentData` 中每条记录都有完整字段：`college`、`className`、`name`、`studentId`、`isDrawn`。
3. 所有 `college` 值都属于当前 5 个学院之一。
4. `studentId` 没有重复。
5. 打开 `admin.html` 后学院特殊礼物抽奖仍显示 5 个学院。
6. 普通抽奖和学院抽奖能从新名单中抽出学生，展示姓名和班级。

## 非目标

- 不引入后端服务。
- 不在浏览器运行时解析 Excel。
- 不保存手机号、IP、投票选择等字段。
- 不改变抽奖算法、去重逻辑或大屏动画。
